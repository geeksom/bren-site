# Bren knowledge base

Canonical facts and messaging for Bren (fictional product, getbren.com). These files are the single source of truth: the site copy is written from them, and they are meant to be uploaded as context to the on-site AI assistant (Konvars).

| File | Use it for |
|---|---|
| `00-messaging-reference.md` | How to write Bren copy: positioning, personas, voice, page playbooks, objections, banned words, LLM block |
| `01-product.md` | What Bren is and does; every feature; roadmap; limits |
| `02-positioning.md` | Category, one-liner, value props by persona, differentiation, fictional proof roster, approved promises |
| `03-icp.md` | Who is a fit; disqualifiers; trial vs. demo routing |
| `04-buying-committee.md` | Roles in a purchase; their goals, objections and answers; ROI math; qualifying questions |
| `05-pricing.md` | Plans, seats, overage, billing, trial rules, refunds, discounts, edge cases |
| `06-security-compliance.md` | Certifications, data handling, encryption, residency, AI/training policy, permissions, HR notes |
| `07-onboarding-support.md` | Getting started, rollout timelines by plan, adoption, support tiers, edge cases |
| `08-integrations.md` | All 19 integrations, scopes, read/write, roadmap |
| `09-objections-faq.md` | 60+ canonical Q&A for the assistant |
| `10-conversion-playbook.md` | How the assistant steers to Start free trial vs. Book a demo |

Rule: when a fact changes, change the numbered doc first, then `00-messaging-reference.md`, then the site (`src/content/`), then rebuild.
